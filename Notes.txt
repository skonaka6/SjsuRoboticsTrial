# Setting up project environment (Arduino IDE)

Setup:
1) Download App executable from https://www.arduino.cc/en/software/, give -x perms if needed
2) Connect board via usb c*, LED on board should turn on
3) In IDE, select Tools > Processor: "ATmega328P (Old Bootloader), Tools > Boards: "Arduino Nano", and Tools > Port: "/dev/ttyUSB0"**
4) Add libraries (for this project, Adafruit MPU6050)
5) Ready to code. Click Verify and then Upload. Example code available in File > Examples > ... Website documentation available at https://docs.arduino.cc/built-in-examples/
6) Set Serial Monitor baud rate to be equal to the 6050's baud rate or output will be gibberish


*Some sites and quick google search say to use Mini B usb, but it seems that is for older products and recent years have implemented USB C.
**(Linux) If port doesn't show up, even after reconnecting the board, it's probably needs permission and BRLTTY may be conflicting. See section on Removing BRLTTY Conflict. Also section on Giving Access to Serial Ports
Removing BRLTTY conflict
Linux comes with a background service BRLTTY for braille display that will hog the port an Arduino Nano uses. Uninstall or disable+mask the service.
https://support.arduino.cc/hc/en-us/articles/29350073597468-Resolve-BRLTTY-conflict-on-Linux
In terminal:
# See if service is running
$ ps -C brltty
# See if BRLTTY is kicking out the board
$ dmesg
ftdi_sio 3-4:1.0: FTDI USB Serial Device converter detected
usb 3-4: FTDI USB Serial Device converter now attached to ttyUSB0
usbfs: interface 0 claimed by ftdi_sio while 'brltty' sets config #1
ftdi_sio ttyUSB0: FTDI USB Serial Device converter now disconnected from ttyUSB0
# if uninstalling completely, use following and reconnect the board
sudo apt remove brltty
# if only disabling, run these 4 commands and reconnect
sudo systemctl stop brltty-udev.service
sudo systemctl mask brltty-udev.service
sudo systemctl stop brltty.service
sudo systemctl disable brltty.service

# MPU 6050 tutorial
tutorial 1: https://www.youtube.com/watch?v=1gNNoFwu9Nc
tutorial 2: https://www.youtube.com/watch?v=SVI_NldMjlE

Used tutorial 1 to practice Examples > Adafruit MPU6050 > basic_readings example. Learned the following:
- MPU6050 communicates via I2C protocol, using Serial DAta line SDA connected to pin A4, and Serial CLock connected to pin A5
- MPU Motion Processing Unit is an IMU Inertial Measurement Unit with 3 gyroscopes and 3 accelerometers
- MPU (and other external boards) don’t need a resistor component connecting because they have built in resistors and have “weak pull-up resistors” (something to read about later)
- The Serial Monitor (seemingly the microcontroller’s equivalent for an output terminal) MUST be set to a matching baud rate or serial output will be gibberish
- The reset button on the Nano is very useful. That thing that looks like a button on the MPU is not a button.
- code from tutorial 2 is not likely to match up with what I will be using since it uses a different library (not adafruit’s) but still has a lot more code segments that may have useful equivalents to look up and use later.




# Learning Servos
Kit provide Miuzei MS18 9g (gram) Micro Servo

Sparkfun Electronics, “Quick Guide to Servos”
https://www.youtube.com/watch?v=vbAZdQGTA0s
Video notes:
- Servos generally come in 3 sizes, [Micro, Standard, Jumbo/Giant]
- 3 wires => {Power (usually 5V), Ground, Control}
- Control is done via PWM Pulse Width Modulation. Servo expects a pulse every 20ms, and width of pulse determines the position
- If you dissect a servo, you’ll find it made of a DC motor, control IC, and Potentiometer for positioning feedback (sounds like it might not be too hard to create a servo from scratch?), and two stops that limit the position to 180 degrees
- PositionalServos can control Speed, Direction, and Position
- Continuous Servos have NO stops and can rotate forever, but lose Position control

MY CREATIVE ENGINEERING, “Beginner’s Guide: Using SG90 and MG90 Servo Motors with Arduino”
https://www.youtube.com/watch?v=niMjFyKXrCQ
Video notes:
- Wires: {Power (VCC) : red, Ground : brown, Control : orange/yellow}
- connect Control to PIN 9 on arduino
- video provides sample code for positioning the servo on loop (set to angle 0, 90 180, loop)
- demo powers micro servo directly from arduino

Other notes
- Normally you want to power the arduino with an external (battery) source, the arduino may have the voltage but usually lacks the amperage to move loads or larger servos (exception: Is probably fine using a micro servo with no load, for short periods)
- Yes you need the screw to attach the arm (“servo horn”). Use the small screw (https://www.youtube.com/watch?v=fbq6pyq1x4U)
